# RutaConecta-S.A.S
Arquitectura Empresarial Serverless y Orientada a Eventos en Google Cloud Platform (GCP) para RutaConecta S.A.S., plataforma consolidadora de turismo rural B2B en Colombia. Incluye diagramas C4/PlantUML, estimación de costos de producción y especificaciones técnicas para procesamiento de alta concurrencia e integración asíncrona con WhatsApp.
